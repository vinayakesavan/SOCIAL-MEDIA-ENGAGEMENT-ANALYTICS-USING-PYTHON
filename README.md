                               SOCIAL MEDIA ENGAGEMENT ANALYTICS USING PYTHON
1. Overview
This assignment focuses on analysing social media engagement data using Python.
The dataset contains information such as likes, comments, shares, impressions, watch time,
engagement rate, user details, post categories, post types, sentiment, and device information.
The project involves importing and cleaning the dataset, performing data transformation and statistical
analysis, exploring patterns with Pandas and NumPy, and creating visualizations using Matplotlib, Seaborn,
and Plotly. The analysis aims to understand content performance, user behaviour, engagement trends,
and the factors that may influence social media interactions.

2. Objectives
•	To import, explore, and understand the structure of the social media engagement dataset using Python.
•	To clean and preprocess the dataset by handling missing values, duplicates, inconsistent data, and incorrect data types.
•	To perform Exploratory Data Analysis (EDA) to identify patterns and trends in social media engagement.
•	To analyse content performance across post types, content categories, and countries.
•	To understand user engagement trends based on age and account verification status.
•	To examine audience behaviour through day-wise impressions and device-wise watch time.
•	To perform sentiment analysis to understand engagement patterns across positive, negative, and neutral posts.
•	To create meaningful static and interactive visualizations using Matplotlib, Seaborn, and Plotly.
•	To generate meaningful insights from the dataset that can support data-driven social media content strategies.
